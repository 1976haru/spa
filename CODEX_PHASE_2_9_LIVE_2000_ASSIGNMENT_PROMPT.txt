4. Candidate harvesting for 2,000
==================================================

Current manual one-page capture is too cumbersome for 2,000.

Implement a conservative assisted search-page campaign using ONE ShopSource-owned Amazon search worker tab.

Important:
- no CAPTCHA bypass
- no stealth
- no proxy rotation
- no cookie/session extraction
- no hidden API
- no Amazon private endpoints

Use normal browser navigation only.

Flow:
1. User explicitly starts LIVE 2000 campaign.
2. ShopSource opens Amazon search page for current keyword.
3. Capture rendered search result cards.
4. Store/dedupe candidates.
5. Wait a conservative configurable delay.
6. Navigate same search worker tab to next Amazon search result page.
7. Repeat until:
   - candidate target reached
   - page exhausted
   - CAPTCHA detected
   - user pauses/cancels
8. Then move to next keyword.

Default search-page delay:
8 seconds

Allowed UI range:
6–30 seconds

Never go below 6 seconds in live mode.
