    mapping_valid = ... and remote_count > 0

But shopify_collection_mappings.published_ids_json stores PUBLICATION IDs (for example Online Store publication IDs), not collection PRODUCT IDs.

Evidence from src/shopsource/shopify_collections.py:
- result["published_ids"].append(pub["id"])
- published_ids_json persists result["published_ids"]
- Shopify collection actual member count is available separately as productsCount { count precision }

Therefore the current readiness code can falsely treat:
"mapped + published to Online Store"
as:
"mapped + nonempty collection"

That is incorrect.

are separate evidence fields.
