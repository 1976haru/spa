============================================================
A. TEST PHILOSOPHY
============================================================

Build a reusable Production Rehearsal harness around EXISTING ShopSource services.
Do not build a parallel fake business application.

Rules:
1. Exercise real orchestration/service/domain code wherever possible.
2. Replace only external side-effect adapters with deterministic simulators/fakes.
3. Use the same validation/preflight/backup/post-write logic that production uses.
4. Do not weaken assertions to make tests pass.
5. When a test exposes a real defect:
   - fix production code
   - add a regression test
   - rerun focused tests
   - rerun complete rehearsal
   - rerun full suite
6. Zero unexpected failures is required for release candidate status.

No new dependency is required. Prefer pytest parametrization + Python random.Random(seed)
instead of adding Hypothesis or heavy browser packages.
