5. BOUNDED BULK READ-ONLY CHECK
======================================================================

Add:
check_store(store_id)
check_all(...)

Requirements:
- read-only only
- never call themeFilesUpsert
- never call Shopify CLI theme push
- never call product/collection mutation
- max concurrency small and bounded, e.g. 4
- per-store timeout / failure isolation
- one store failure must not abort remaining stores
- deterministic final order by store_id
- report counts

For stores without Shopify connection:
- do not attempt remote CLI/GraphQL
- mark NEEDS_SETUP

For stores with GraphQL read capability:
- identify current MAIN theme

For stores with Theme Access credential:
- perform existing exact theme ID / role capability check

For stores without Theme Access credential:
- mark CREDENTIAL_MISSING without asking for one during batch run

No interactive prompts inside batch check.

======================================================================
10. BULK STATUS SEMANTICS
======================================================================

Define high-level status consistently.

READY:
- Shopify configured
- MAIN theme identified
- AUTO backend selected and ready

NEEDS_SETUP:
- missing Shopify connection
- Theme Access credential missing AND GraphQL not ready
- CLI missing when GraphQL not ready
- MAIN identity unavailable

ERROR:
- network/auth/parser unexpected error

NOT_CHECKED:
- no current/cached check

Do not call a store READY merely because Theme Access credential exists.
Exact MAIN identity and actual backend capability must be verified.

======================================================================
11. GRAPHQL SEMANTICS
======================================================================

Reuse current honest evidence model:
- SCOPE_MISSING
- SCOPE_GRANTED_UNVERIFIED
- VERIFIED_ACTIVE
- ACCESS_DENIED_LAST_ATTEMPT

Dashboard "GraphQL READY" count should count only VERIFIED_ACTIVE/currently usable GraphQL backend.

SCOPE_GRANTED_UNVERIFIED is NOT READY.

Do not perform explicit GraphQL verification probe from bulk check.
That probe is a live write and belongs to Featured apply flow only.

======================================================================
12. THEME ACCESS SEMANTICS
======================================================================

Theme Access READY requires:
- credential present
- supported Shopify CLI
- exact store configured
- exact theme ID found
- known role
- identity verified

Do not mark READY from credential existence alone.

If Shopify CLI is missing:
show CLI_NOT_INSTALLED clearly.

Do not attempt automatic CLI installation in this phase.

- progress indicator for bulk check
