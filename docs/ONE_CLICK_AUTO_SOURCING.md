# 스토어 자동 소싱 계획 (Phase 3.0)

사용자는 스토어의 소싱 목표를 입력하고 자동 소싱 계획을 한 번 만들면 됩니다. 카테고리, 키워드 후보군, 각 카테고리의 목표량(quota), 우선순위는 Store Profile과 로컬 MASTER/키워드 이력으로 결정적으로 구성됩니다. 계획 생성은 로컬 SQLite만 사용하며 네트워크/API를 호출하지 않습니다.

키워드 pool은 검토와 향후 실행을 위한 내부 후보 목록입니다. 전부 실행하지 않으며 기본값은 카테고리당 최대 활성 keyword 15개, keyword당 최대 5페이지, 연속 무성과 2페이지, keyword당 고유 후보 300개입니다. 고급 설정에서 활성 keyword 상한(3–30), 페이지 상한, 무성과 페이지 및 후보 상한을 바꿀 수 있습니다. 위험/제외어와 낮은 점수 키워드는 삭제하지 않고 비활성 상태로 보존합니다.

상세 목표는 기본적으로 후보 목표의 100%입니다. 고급 설정에서 상세 보강 비율을 줄일 수 있습니다. quota 합계는 후보 목표와 정확히 일치하며, 계획 생성 때마다 이전 계획을 덮어쓰지 않는 새 버전 snapshot을 만듭니다.

이 단계의 버튼은 계획만 저장하며 Amazon 검색, 브라우저 실행, Shopify 업로드를 시작하지 않습니다. 실제 계획 실행은 Phase 3.1에서 연결합니다. 실행 전 만들어 둔 snapshot은 계획 버전과 설정을 보존합니다.
