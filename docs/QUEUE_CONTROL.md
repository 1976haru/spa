# 자동 작업 대기열 사용법

- `일시정지`: 현재 atomic 작업 경계에서 멈춥니다. 이미 완료한 결과는 유지됩니다.
- `계속`: 마지막 checkpoint부터 이어서 실행하며 성공한 task는 반복하지 않습니다.
- `중단`: 앞으로 실행할 task만 STOPPED로 바꿉니다. 자동 rollback이나 삭제를 하지 않습니다.
- `실패만 재시도`: FAILED task만 제한 횟수 안에서 다시 실행합니다.

앱을 다시 시작했을 때 미완료 queue가 있으면 홈 화면에 “중단된 자동 작업이 있습니다”와 `이어서 실행`, `종료 상태로 두기`가 표시됩니다.

기본 activity feed는 최근 50개만 표시합니다. 수천 개 task도 UI에 한꺼번에 렌더하지 않고 50개 단위로 조회합니다.
