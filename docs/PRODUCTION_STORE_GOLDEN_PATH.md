# Cabin Tidy 실전 스토어 Golden Path

이 화면은 과제 제출이 아니라 실제 운영을 위한 준비 상태를 보여줍니다. 기존 소싱, Source Safety, StoreBuild, 자산·홈페이지, StoreCompletion 기능을 다시 만들지 않고, 그 결과를 production gate와 증거로 관리합니다.

## 초보자 사용 순서

1. 왼쪽 메뉴에서 **실전 스토어 완성**을 엽니다.
2. **실전 스토어 자동 구축 시작**은 로컬 점검 run과 checkpoint만 준비합니다. 이 구현 단계에서 Shopify/Amazon/Keepa/Theme에 연결하거나 변경하지 않습니다.
3. 각 gate가 요구하는 실제 근거를 기존 모듈에서 확인합니다. 연결하지 않은 정보는 READY가 아니라 확인 필요/입력 대기로 남습니다.
4. 상품은 DRAFT 파일럿부터 시작합니다. 10개 결과를 Shopify에서 다시 읽고 검증한 뒤에만 다음 단계 50개, 200개를 별도 검토합니다.
5. ACTIVE 공개는 DRAFT 생성과 별개이며 모든 안전 gate와 사용자의 별도 확인이 필요합니다.

## 중요한 안전 원칙

- 재고 스냅샷은 판매 가능의 증거입니다. `PRIMARY` 분류나 상품 수가 이 증거를 대신하지 않습니다.
- Amazon 페이지에서 보이는 이미지가 재사용 허가를 뜻하지 않습니다. 권리가 확인되지 않은 정확한 상품 이미지는 ACTIVE 대상이 아닙니다.
- 생성형 라이프스타일 이미지는 hero/컬렉션 분위기용입니다. 실물 상품 사진을 대신할 수 없습니다.
- 표시 가격은 Source 가격과 분리하고, 명시적인 판매가 및 margin policy가 없으면 production 통과로 취급하지 않습니다.
- 검증되지 않은 정책/회사 정보, 결제·배송·세금 상태는 지어내지 않습니다.
- 전체 통과 점수와 무관하게 blocker가 하나라도 있으면 출시 준비가 아닙니다.

## 결과 파일

점검 결과는 `exports/production_runs/<store>/<run_id>/`에 저장합니다. JSON/CSV 및 `final_launch_report.md`에는 token이나 credential을 기록하지 않습니다.

## 제한

소프트웨어 검사는 사람의 상품권리 검토, 실제 모바일 시각 검수, 법률 검토, 결제/배송/세금 설정 확인을 대체하지 않습니다. 화면이 gate를 준비했다고 Shopify 변경이 수행되는 것은 아닙니다.
