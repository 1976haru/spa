# 수동 작업 안내

다음 항목은 사업자 또는 Shopify 관리자가 직접 확인해야 합니다.

- 지원 이메일, 회사 법적 이름·주소·전화번호
- 반품 기간·주소, 처리·배송 시간과 요금
- Privacy, Terms, Refund/Returns, Shipping 정책의 최종 검토
- 실제 배송 origin/location, 미국 배송 가능 rate/profile
- 세금 설정과 의무에 대한 전문가 검토
- 사용할 수 있는 결제 수단 한 개 이상
- 도메인·SSL·스토어 비밀번호·published theme 상태
- checkout/customer 설정과 실제 launch 승인
- 미디어 사용 권리와 수동 접근성 감사

ShopSource는 모르는 값을 지어내지 않고 `REQUIRES_BUSINESS_INPUT` 또는 `MANUAL_ACTION_REQUIRED`로 표시합니다. Phase 4.2 LIVE 테스트 전에 위 항목을 채우고 검토 기록을 남겨야 합니다. 실제 주문이나 결제는 Phase 4.0에서 실행하지 않습니다.
