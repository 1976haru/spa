# 스토어 완성 마스터

Phase 4.0은 상품부터 결제 준비까지 29개 영역을 한 계획에서 확인합니다. 기존 상품 동기화, 컬렉션, 브랜드, 내비게이션, 홈페이지 결과는 복사하지 않고 해당 plan/run ID를 참조합니다.

각 영역은 `VERIFIED`, `MANUAL_ACTION_REQUIRED`, `BLOCKED` 중 하나로 끝납니다. 자동화가 안전한 로컬 계획은 미리 만들 수 있지만, Shopify 페이지·테마·정책 쓰기와 결제·배송·세금·도메인 결정은 자동 실행하지 않습니다.

초보자는 **스토어 완성** 화면에서 완료, 수동 작업, 차단만 확인하면 됩니다. 고급 설정에는 데이터 출처, ID, 검사 상세가 접혀 있습니다.

Phase 4.1은 대량 데이터와 브라우저/device stress simulation을 수행하고, Phase 4.2는 사람이 필수 설정을 확인한 뒤 Cabin Tidy의 통제된 LIVE 테스트를 수행합니다.
