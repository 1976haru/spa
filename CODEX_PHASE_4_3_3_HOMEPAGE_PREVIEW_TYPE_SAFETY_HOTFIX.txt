Observed real Cabin Tidy failure
1) Featured products selection/review is working:
   - 4/4 READY
   - review dialog works
2) User then clicks Homepage Auto Design / Featured Product Preview.
3) Error shown:
   'list' object has no attribute 'strip'
4) Featured preview then reports:
   MANUAL_ACTION_REQUIRED · Shopify write 없음

Root cause confirmed from current source
In src/shopsource/homepage_automation.py, hero_image_prompt():
    avoid = profile.get("avoid_styles", "").strip()
But Brand Profile may validly store avoid_styles as a list.
Calling .strip() on a list throws exactly:
    'list' object has no attribute 'strip'
Because homepage auto design crashes before a valid theme snapshot/preview is fully stored, Featured Product Preview then runs against an empty/not-checked snapshot and falls back to MANUAL_ACTION_REQUIRED.

This hotfix must fix BOTH:
A. the type-safety bug
B. the poor UX where Featured Product Preview requires the user to separately know that homepage/theme prerequisites must already be loaded.

======================================================================
1. TYPE-SAFE BRAND PROFILE TEXT NORMALIZATION
======================================================================

Add a small reusable helper in an appropriate module, e.g.:
normalize_prompt_text(value, separator=", ")

Requirements:
- None -> ""
- str -> stripped string
- list/tuple/set -> normalize each scalar element and join
- dict -> stable readable text (prefer values or "key: value"; do not emit Python repr noise)
- numbers/bool -> str(value)
- nested lists -> flatten safely if reasonable
- never throw merely because a BrandProfile text-like field is list/dict

Use this helper in hero_image_prompt() for at least:
- avoid_styles
- personality
- brand_keywords
- colors/palette if needed
and audit nearby homepage prompt code for the same unsafe assumption.

Do NOT silently mutate the stored Brand Profile. This is display/prompt normalization only.

3. FEATURED PREVIEW SHOULD AUTO-ENSURE THEME SNAPSHOT
======================================================================

Current UI featured_preview() calls:
FeaturedProductAssignmentService().build_theme_preview(plan, state.get("snapshot") or {})

This is fragile because a fresh UI session may have:
- a valid featured-products plan
- no homepage state snapshot yet

Change featured_preview() so it is one-click beginner-safe:

When clicked:
1. Verify current featured plan exists.
2. If state.snapshot is missing, NOT_CHECKED, stale, or lacks theme_files/template:
   run READ-ONLY ShopifyThemeReader().discover(current_store)
3. Store the snapshot in state.
4. If the theme read fails/missing read_themes:
   show a precise Korean message and stop.
5. Call build_theme_preview() with the real fresh snapshot.
6. Show the actual reason when status != PREVIEW.

No Shopify write.

Do not require the user to separately click "홈페이지 자동 설계" just to load theme metadata for featured preview.
