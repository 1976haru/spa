ShopSource Studio GitHub 연결 순서

1) GitHub에서 새 PRIVATE 저장소 생성
   Owner: 1976haru
   Repository: shop-source-studio
   README/.gitignore/license 자동 생성은 체크하지 않음 (로컬에 이미 있음)

2) 이 프로젝트를 아래 폴더에 둠
   D:\shop\shop-source-studio

3) PowerShell
   cd D:\shop\shop-source-studio
   git status
   git remote add origin https://github.com/1976haru/shop-source-studio.git
   git push -u origin main

4) Codex 실행 후 루트의 CODEX_PHASE_1_PROMPT.txt를 그대로 사용

주의:
- data/*.sqlite3, exports/*, .env는 GitHub에 올리지 않음
- Spark storage.zip 원본도 Git에 올리지 않음
