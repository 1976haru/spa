4. LOGO GENERATION STRATEGY
======================================================================

Primary design goal:
professional horizontal Shopify header logo with exact readable brand name.

Important reliability rule:
Do NOT depend on image generation alone to spell the brand name correctly.

Implement two-stage logo pipeline:

A. BRAND MARK GENERATION
- optional AI-generated simple symbol / mark
- no words in the AI mark generation prompt
- simple silhouette
- transparent or easily removable background
- small-screen legibility

B. DETERMINISTIC WORDMARK COMPOSITION
- compose exact brand_name text programmatically
- combine approved/generated mark + exact text
- deterministic layout
- exact spelling guaranteed
- export PNG and, where practical, SVG
- use bundled/system-approved font strategy with graceful fallback
- do NOT commit font files
- record actual font family used

This architecture is preferred over asking the image model to render “CABIN TIDY” text.

Support manual uploaded mark/logo as provider fallback.

6. FAVICON GENERATION STRATEGY
======================================================================

Favicon must inherit the same identity.

Preferred source:
approved LOGO_MARK.

Do not generate an unrelated second logo.

Pipeline:
approved mark
→ square master
→ simplify if needed
→ center/pad
→ favicon_master.png
→ resize with high-quality downsampling
→ favicon_32.png

Final assignment-compatible output:
32×32 PNG.

Also allow 48/64/180/192/512 derivative generation for future use,
but 32×32 is mandatory.

Validation:
- exactly 32×32 for FAVICON_32
- no tiny unreadable wordmark
- sufficient contrast
- non-transparent meaningful content
- safe padding
- same brand palette as logo
