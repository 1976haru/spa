Why this task exists
The multi-store backend is ready, but the current UI is still developer-oriented:
- English-heavy labels
- raw technical states such as SCOPE_MISSING, CREDENTIAL_MISSING, NO_WRITE_BACKEND
- operator must understand GraphQL / CLI / backend before knowing what to click

The real user is a complete beginner.
The UI must make the correct next action obvious without requiring knowledge of Shopify API terminology.

Mission
Polish ONLY the multi-store theme operations UI and presentation helpers so:
- Korean-first
- beginner-first
- one obvious next action
- technical codes preserved but hidden under details
- no weakening of safety
- no Shopify mutation
- no automatic credential creation
- no bulk live apply
