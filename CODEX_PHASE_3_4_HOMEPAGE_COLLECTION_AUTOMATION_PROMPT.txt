ShopSource Studio — Phase 3.4
SHOPIFY HOMEPAGE FEATURED COLLECTION AUTOMATION

Prerequisite:
Phase 3.2 collection planner and Phase 3.3 Shopify collection publisher complete.

Goal:
Automate the second half of the collection mission:
place selected collections on the Shopify home page as Featured Collection sections.

This is theme-sensitive and must be safer than product/collection API sync.

==================================================
0. Safety
==================================================

Never edit live theme blindly.

Before any change:
- identify current published theme
- download/read relevant theme JSON/schema
- create backup snapshot
- dry-run proposed JSON diff
- user explicit confirmation required

Do not perform live theme write during Codex implementation/tests.

==================================================
1. Shopify scopes/API
==================================================

Check official current Shopify API requirements for theme read/write.
Do not assume scope availability.

If write_themes is unavailable/not approved:
fall back to:
- generate exact theme change plan
- export patch/manual instructions
- do not use browser-click automation as default

==================================================
2. Theme detection
==================================================

Identify published theme and templates/index.json or equivalent.

Inspect available section types/schema.

Find a section type that corresponds to:
- featured collection
- collection
- collection list

Do not assume Dawn schema on all stores.

==================================================
4. Dry-run diff
==================================================

Generate:
- current theme JSON snapshot
- proposed theme JSON
- structured diff
- sections to add
- collection handles/IDs
- order

No write yet.

==================================================
5. Apply
==================================================

Only explicit button:
[홈페이지 추천 컬렉션 적용]

On apply:
- backup current theme config
- write smallest possible change
- re-fetch/verify
- provide rollback button using backup

No unrelated theme formatting changes.

==================================================
6. Idempotency
==================================================

Repeated apply must not duplicate the same Featured Collection section.

Map ShopSource section IDs in theme settings where possible.

If user manually moved/edited section:
detect drift and show conflict.
