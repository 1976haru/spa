3. ONE-CLICK "자동" MODE
======================================================================

Add a clear automation mode.

Top-level:
[자동 실행]

Optional modes:
AUTO
REVIEW
MANUAL

Default for beginner:
AUTO

AUTO means:
run every safe, non-destructive, already-configured step automatically in sequence.

AUTO must automatically:
1. inspect prerequisites
2. calculate work queue
3. run safe read-only checks
4. run mock/local planning
5. run configured provider checks after required cost confirmation
6. evaluate sellability
7. classify results
8. produce reports
9. move to next safe step
10. retry transient failures within bounded policy
11. resume from checkpoint after restart
12. stop only at a HUMAN GATE

HUMAN GATE examples:
- Keepa paid-token execution confirmation if cost exceeds or if provider call is chargeable
- real Shopify write
- theme write
- Spark handoff/manual app operation
- legal/business data input
- shipping/payment/tax/domain decisions
- ambiguous conflict
- credentials missing
- CAPTCHA/robot check
- rights review
- potentially destructive action

AUTO should not stop after every harmless step just to ask "continue?".

======================================================================
6. QUEUE CONTROLS
======================================================================

Add clear controls:

[일시정지]
[계속]
[중단]
[실패만 재시도]

Behavior:

Pause:
- finish current atomic/safe boundary
- persist checkpoint
- mark PAUSED
- no new task starts

Resume:
- reload persisted queue
- continue from last checkpoint
- do not repeat successful tasks

Stop:
- stop future tasks safely
- preserve completed work
- mark STOPPED
- no rollback unless explicitly chosen

Retry failed:
- only FAILED tasks
- respect retry limits
- do not rerun SUCCEEDED tasks

On app restart:
show:
"중단된 자동 작업이 있습니다."

Buttons:
[이어서 실행]
[종료 상태로 두기]

======================================================================
7. AUTOMATIC RETRY POLICY
======================================================================

Transient:
- timeout
- network interruption
- 429/throttle
- temporary provider/server error

Auto retry with bounded exponential backoff.

Permanent:
- bad credential
- missing scope
- invalid business input
- malformed permanent API userError
- product conflict requiring human decision
- CAPTCHA

Do NOT endlessly retry.

User-facing text:
"일시적인 오류라 자동으로 다시 시도 중입니다. (2/4)"

Do not expose stack traces by default.
