======================================================================
3. PRODUCT ELIGIBILITY — HARD RULES
======================================================================

A product can be shown only if:
- it exists in MASTER
- it has a store decision eligible for this store
- it has a shopify_product_mappings row
- remote Shopify identity matches the mapping
- product link/handle is non-empty and real
- product is storefront-eligible for the intended live section
- price is valid
- image is available for assignment-quality presentation, or item is marked NEEDS_IMAGE and blocked from final assignment-ready status
- no duplicate shopify_product_id
- no duplicate handle

Do NOT:
- fabricate product IDs
- fabricate links
- reuse source acquisition price as retail price
- activate DRAFT products automatically
- publish products automatically just to satisfy the assignment
- add fake discounts
- add fake urgency
- add fake stock countdown
- add fake reviews/social proof

If there are fewer than 4 eligible visible products:
status = MANUAL_ACTION_REQUIRED or BLOCKED
with an exact reason.

4. RECOMMENDED PRODUCTS COLLECTION STRATEGY
======================================================================

The assignment should work across theme capabilities.

Preferred reusable strategy:
A. If theme supports direct product-list/product blocks with proven schema:
   render selected verified products directly.

B. Else if theme supports Featured Collection:
   use a ShopSource-managed showcase collection, e.g.
   collection_key = homepage-new-arrivals
   title = New Arrivals

Do not create a separate unrelated collection subsystem.
Reuse existing collection publisher and product owned-tag behavior where possible.

If a managed New Arrivals collection is needed:
- use ShopSource-owned tag/rule semantics
- add only ShopSource-owned tag(s), never replace merchant tags
- collection membership must reflect selected assignment items
- avoid destructive deletes
- if an existing merchant New Arrivals collection conflicts, return CONFLICT / SAFE_ADOPT options
- never silently hijack an unrelated merchant collection with the same title

C. If neither safe native pattern exists:
MANUAL_ACTION_REQUIRED
Generate exact Shopify Theme Editor/PageFly manual instructions.
Do not automate external GUI clicks.
