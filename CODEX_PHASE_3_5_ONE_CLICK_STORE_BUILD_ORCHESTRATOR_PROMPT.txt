Use the current supported Shopify product APIs. Prefer productSet for external catalog synchronization where it fits, and use current bulk/variant/media APIs as needed after inspecting official 2026-07 docs.

3. PRODUCT IDENTITY / IDEMPOTENCY
======================================================================

Never identify products only by title.

Stable ShopSource identity:
- source platform
- source product ID / ASIN
- store ID

Maintain local mapping:
store_id
master_product_id
source_id
shopify_product_id
shopify_handle
last_payload_hash
last_remote_hash
sync_status
synced_at

Prefer a ShopSource-owned metafield or another stable supported identifier in Shopify for reconciliation.

Repeated runs:
- CREATE first time
- UPDATE when owned fields changed
- NO CHANGE when payload hash unchanged
- CONFLICT if remote manually changed an owned field and conflict cannot be safely resolved
- never duplicate the same source product

Never automatically delete Shopify products.
