CONFIRMED ROOT CAUSE
The live featured-products section was written to templates/index.json with:
  ss_featured_products_e193a01e

Shopify's JSON template specification requires section instance IDs and block IDs to contain ONLY alphanumeric characters.
Underscores are invalid.

Official Shopify docs:
- JSON template section data: <SectionID> accepts only alphanumeric characters.
- <BlockID> also accepts only alphanumeric characters.

Current code generates multiple invalid managed IDs with underscores:
- homepage_featured_products.py:
  ss_featured_products_<hash>
- homepage_automation.py:
  _managed_id() returns ss_<kind>_<hash>
- homepage_collections.py:
  _section_id() returns ss_<slug>_<hash>
- category block IDs can also inherit invalid underscores.

Observed consequence
- Isolated apply returned VERIFIED because it verified JSON write/readback and product IDs.
- Public storefront did not render the New Arrivals section.
- Current "VERIFIED" therefore means remote JSON equality, NOT storefront visibility.

Mission
Fix the ID architecture once, migrate the already-written invalid ShopSource featured section safely, and prevent future false-positive storefront verification.

Do NOT perform a real Shopify write during implementation/testing.
