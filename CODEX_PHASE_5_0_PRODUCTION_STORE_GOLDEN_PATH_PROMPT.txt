3. G1 — SOURCING QUALITY, NOT JUST QUANTITY
======================================================================

Audit the entire current MASTER/catalog for Cabin Tidy.

Do not use a fixed hardcoded source count.

Evaluate per product:
- store relevance
- exact category fit
- duplicate identity/ASIN
- source title quality
- source URL/reference
- image availability metadata
- ratings/review counts if available
- source price presence
- source option/variant ambiguity
- restricted/risky classification
- obvious bundles/multipacks that can cause pricing confusion
- incompatible/vehicle-specific fitment requiring unsupported claims

Production sourcing statuses should distinguish:
- PRODUCTION_CANDIDATE
- RESERVE
- REVIEW_REQUIRED
- REJECT_FOR_STORE
- RESTRICTED

MASTER retention rules remain intact. Reject-for-store does not delete from MASTER.

Add collection coverage report:
- each target collection candidate count
- underfilled collection
- overbroad collection
- overlap rate
- unmatched rate

No target count is considered success by itself.

======================================================================
4. G2 — SOURCE SAFETY
======================================================================

Reuse Phase 4.1.1.

Publishable product requires:
- fresh source snapshot
- availability = IN_STOCK
- no SOURCE_ERROR
- freshness within policy
- sellability pass
- no source-safety blocker

UNKNOWN is not publishable.

Persist snapshot fingerprint and invalidate preview if source changes.

======================================================================
5. G3 — PRODUCT CONTENT QUALITY
======================================================================

Create/strengthen production product-content audit.

Every publishable item must have:
- human-readable English storefront title
- no Amazon marketplace junk text
- no ALL CAPS spam
- no unsupported superlatives
- concise benefit-oriented description
- factual features supported by source evidence
- dimensions/material/compatibility only when supported
- variant names normalized
- vendor/brand handling policy
- SKU/identity strategy
- source trace stored internally, not exposed unnecessarily
- SEO title/description within reasonable lengths
- handle stability

Never invent:
- safety certifications
- vehicle compatibility
- weight capacity
- warranty
- material
- dimensions
- delivery promise
- country of origin

If source evidence is insufficient, mark REVIEW_REQUIRED.

Add product quality score, but BLOCKERS override score.

======================================================================
6. G4 — PRODUCT MEDIA QUALITY / RIGHTS
======================================================================

This gate is critical because the user wants to rebuild from sourcing images correctly.

Add explicit product media policy per store/product:
- SUPPLIER_AUTHORIZED
- MERCHANT_OWNED
- LICENSED
- GENERATED_LIFESTYLE_ONLY
- MANUAL_REVIEW_REQUIRED
- NO_RIGHTS_CONFIRMED

Do NOT assume Amazon listing images can legally be reused merely because they are visible.

Production ACTIVE publication requires an allowed media policy.

If exact product imagery rights are not confirmed:
- keep product DRAFT
- allow prompt generation for generic collection/hero lifestyle assets
- do NOT generate fake exact-product photographs that could misrepresent the sourced item

Media audit per product:
- at least one usable primary image for publishable product
- adequate resolution
- not a broken URL
- no obvious watermark when detectable from metadata/manual review
- no duplicate unrelated image
- variant image consistency when applicable
- alt text factual

Collection/hero generated lifestyle images are separate from exact product media.

======================================================================
7. G5 — PRICING / MARGIN
======================================================================

Reuse SourcePriceGuardPolicy.

Production product requires an explicit store pricing policy.

Never use source/Amazon price directly as Shopify selling price by accident.

Calculate:
- current source cost
- configured buffer
- known fees when configured
- minimum margin amount
- minimum margin percent
- selling price
- source-price delta since preview

If fee components are unknown, do not call margin 'safe' unless policy explicitly defines how unknown fees are handled.

AUTO_REPRICE remains OFF by default.

Source price increase can block/pause new listing according to policy.

17. G15 — BATCH EXPANSION
======================================================================

→ preview fingerprint
→ explicit write confirmation
→ write
→ reread verify
→ reconciliation report

Do not duplicate products.
