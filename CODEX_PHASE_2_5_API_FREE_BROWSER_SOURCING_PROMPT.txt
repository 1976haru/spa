==================================================
0. 목표
==================================================

사용자는 Keepa 등 유료 API 없이도
Spark Center에 올릴 수 있는 상품자료를 완성하고 싶어 한다.

이번 Phase의 최종 운영 흐름:

Store 선택
→ Keyword Studio 추천 주제어
→ Amazon 검색 열기
→ ShopSource Capture 확장으로 현재 검색결과 가져오기
→ 선택 상품 상세 보강
→ MASTER
→ 현재 Store 자동 분류
→ PRIMARY 검토
→ Spark Center 업로드 package 생성
→ ready/<package_id> 폴더 수동 업로드

중요:
이번 Phase의 목표는 "API key 없이도 실제 자료를 완성하는 것"이다.

단:
- CAPTCHA 우회 금지
- WAF 우회 금지
- stealth/proxy rotation 금지
- Amazon cookie/session/localStorage 수집 금지
- undocumented endpoint 사용 금지
- 로그인 자격증명/authorization header 수집 금지

Amazon cookie, session token, 인증값은 저장 금지.

X-ShopSource-Pairing: <token>

이 token은 외부 credential이 아니다.
하지만 Git에 commit하지 마라.

18. Completeness Score
==================================================

예:

ASIN        필수
title       필수
url         10
price       15
image       15
brand       10
category    10
aboutThis   10
overview    10
rating      5
reviewCount 5
options     5
기타        5

정확한 weight는 상수로 분리.

필수 asin/title 없으면 0.

예:
Search result capture만 하면 45~65점.

- Spark Center portal compatibility는 실제 5상품 업로드로 검증 필요
