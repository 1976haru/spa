4. Conditions: current/manual compatibility
==================================================

The user manually created:
Trunk Organizers
Title CONTAINS "Trunk"

Planner should support this exact behavior.

Supported local canonical fields:
- TITLE
- PRODUCT_TYPE
- TAG
- VENDOR
- PRICE
- METAFIELD (future)

Relations:
- EQUALS
- NOT_EQUALS
- CONTAINS
- NOT_CONTAINS
- STARTS_WITH
- ENDS_WITH
- GREATER_THAN
- LESS_THAN

For the current Spark-uploaded catalog, title-based rules are an acceptable fallback.

For future direct Shopify upload, prefer stable ShopSource-generated TAG rules where possible because tags are less brittle than product titles.

Planner output must explicitly record rule strategy:
TITLE_FALLBACK
TAG_PREFERRED
MIXED

==================================================
5. Collection generation rules
==================================================

Default collection count:
- small store: 4–6
- normal niche store: 6–10
- broad niche store: 8–15

Do not create dozens of near-duplicate collections.

For each sourcing category:
1. determine if category is substantial enough
2. generate customer-friendly English title
3. generate concise English description
4. build one or more safe matching conditions
5. estimate product count from local MASTER/store data
6. generate image prompt
7. generate alt text

Do not create empty collections by default unless user enables future/empty collections.

==================================================
6. Avoid overly broad title rules
==================================================

Example:
Title CONTAINS "Car"
would match far too much.

Add quality rules:
- reject overly generic single-word conditions
- prefer distinctive phrases
- combine conditions when needed
- estimate precision against current product titles

Examples for Cabin Tidy:
Trunk Organizers:
  TITLE CONTAINS "Trunk"

Seat Organizers:
  TITLE CONTAINS "Seat Organizer"
  OR TITLE CONTAINS "Backseat Organizer"

Console Storage:
  TITLE CONTAINS "Console"

Cup Holders & Storage:
  TITLE CONTAINS "Cup Holder"

Trash & Cleanup:
  TITLE CONTAINS "Trash"
  OR TITLE CONTAINS "Cleaning"

But do not hardcode Cabin Tidy-only logic; category phrase generation should be reusable.

==================================================
7. Preview matching locally
==================================================

Before Shopify sync:
simulate each collection condition against current MASTER/store products.

Display:
- estimated matches
- sample 5 products
- overlap with other collections
- unmatched percentage

Warn:
- 0 matches
- >70% of entire store in one collection
- extreme overlap with another collection
- ambiguous broad rule

Do not block reasonable overlap; products may belong to multiple collections.
