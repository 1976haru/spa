1. 중요한 현재 단서
==================================================

실제 Spark native dataset sample에서는 관측됨:

- quantity: 전부 integer로 관측됨
- images[].main 값: [width, height] 양의 정수 2개
- options:
  selectedVariations: object
  variationDisplayLabels: object
- _listPage: integer
- _collectedAt: epoch milliseconds integer

그러나 현재 Browser package에는 적어도:

- quantity: null
- 과거 5개 상품은 image main dimension이 실제 capture되지 않아 [] 가능
- options variationDisplayLabels가 빈 object일 수 있음

이 값들은 Phase 2.7 validator가 허용했지만,
현재까지 본 Spark native sample에는 동일 형태가 관측되지 않았다.

따라서 이 세 항목을 실제 loader가 필수로 검사하는지 확인해야 한다.

3. Spark 애플리케이션은 READ ONLY 분석
==================================================

목표:
Spark의 "데이터 불러오기"가 dataset JSON을 읽고
전체/포함/제외 목록에 넣는 실제 validation/filter 조건을 찾는다.

Spark 앱 파일은 절대 수정하지 않는다.

가능한 설치 위치를 READ ONLY 탐색:

C:\Users\user\AppData\Local\Programs\
C:\Users\user\AppData\Local\
C:\Users\user\AppData\Roaming\
C:\Program Files\
C:\Program Files (x86)\

spark 실행파일/전자 앱 resources/app.asar/resources 등을 찾는다.

가능하면 현재 실행 중인 Spark process의 executable path도
READ ONLY로 확인한다.

PowerShell/CMD 예:
Get-Process | Where-Object {$_.ProcessName -match 'spark'} | Select Path

앱 수정, DLL injection, patch, hook 금지.

12. quantity 실제 관측
==================================================

quantity가 필수라면 Amazon 상품 페이지에서
실제 DOM으로 관측한다.

우선 후보:

#quantity select
select[name="quantity"]
#selectQuantity

numeric option value/text를 읽고
실제 available numeric choices 중 native scraper 의미와 가장 가까운 값을
loader/native sample과 비교해 결정한다.

예:
native quantity가 1/10/20처럼 나타나는 이유가
quantity selector maximum이라면
그 maximum을 저장한다.

반드시 실제 DOM evidence로 확인.
무조건 1을 넣는 fallback 금지.

관측 불가하면 enrichment FAIL로 표시한다.
