8. PRECONDITION / RACE SAFETY
======================================================================

CLI backend write must use the same safety model as GraphQL:

Before write:
1. read_file current remote
2. compare raw SHA256 against expected_remote_raw_hash
3. if mismatch -> REMOTE_CHANGED_ABORT

Then:
4. create isolated temp theme root
5. write only target file locally
6. execute push
7. pull/read target file again
8. compare exact/semantic expected result

Results:
PRECONDITION_FAILED
WRITE_ATTEMPTED
REMOTE_JSON_VERIFIED
VERIFY_FAILED
ROLLBACK_REQUIRED
ROLLBACK_VERIFIED

10. BACKEND ROUTER / POLICY
======================================================================

Add a router, e.g. ThemeWriteBackendRouter.

Selection rules:

AUTO:
1. If ADMIN_GRAPHQL reports exemption/write_themes active -> ADMIN_GRAPHQL
2. Else if THEME_ACCESS_CLI is READY -> THEME_ACCESS_CLI
3. Else -> NO_WRITE_BACKEND

Explicit selections:
ADMIN_GRAPHQL
THEME_ACCESS_CLI

Never silently switch AFTER a write failure.
Backend selection occurs before mutation and is included in preview/confirmation data.

Return reason codes:
GRAPHQL_EXEMPTION_ACTIVE
GRAPHQL_SCOPE_MISSING_CLI_READY
GRAPHQL_DENIED_CLI_READY
NO_APPROVED_WRITE_PATH
USER_SELECTED_GRAPHQL
