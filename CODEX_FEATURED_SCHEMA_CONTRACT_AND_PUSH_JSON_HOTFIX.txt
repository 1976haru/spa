CONFIRMED CODE BUG
discover_featured_product_schema() currently does:
  next(setting where type in {"product_list", "product"})
and labels either one as DIRECT_PRODUCTS.

build_theme_preview() then does:
  settings[product_field_id] = [four Shopify product IDs]

This means a single-product schema setting:
  {"type": "product", "id": "product"}
can receive a four-item list.

That violates the Shopify schema contract:
- type=product is a single product picker
- type=product_list is the multi-product picker

CONFIRMED PUSH OBSERVABILITY GAP
Shopify CLI theme push --json can report per-asset upload errors in JSON under theme.errors/theme.warning.
The process can complete without the remote asset changing.
Current _push() uses only subprocess returncode and discards JSON output, so it can report an attempted/successful push even when templates/index.json was rejected.
